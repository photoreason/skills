# images

Put the photographer's web-sized photos here, matching the paths in
`../content/site.js`:

```
images/
├── hero.jpg                 full-bleed landing image
├── portrait.jpg             About portrait
├── tidal/01.jpg … 04.jpg
├── city-after-rain/01.jpg … 06.jpg
└── northern-light/01.jpg … 03.jpg
```

**Format:** JPEG or WebP, long edge ~2000px, each under ~500 KB, sRGB.
Convert/compress at <https://towebp.io>. Missing images render as a labelled
placeholder so the layout still reads.
