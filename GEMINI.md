# Photo Reason Skills

This extension provides Photo Reason's open-source skills for photographers —
plain-language, conversational guides for building portfolio websites, curating
and sequencing work, and running creative workflows.

Skills live in `./skills/<name>/SKILL.md`. Load a skill's `SKILL.md` when its
description matches what the user is trying to do. Many skills are written for
people with **no technical background**, so keep language jargon-free and ask
one question at a time via `AskUserQuestion` when a skill calls for it.

Start here: `./skills/portfolio-site-builder/SKILL.md`
